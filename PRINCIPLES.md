# Principles

The functionality Cairn exists to deliver. Every plan should say which of these it serves.

1. **Schedule pre-planned work trees.** Large pieces of Claude Code work, scoped and planned ahead
   of time to the point where the dependencies are known, run without a person kicking off each
   step.
2. **Keep tabs on hands-free work.** While those workflows run, a person can see what is happening
   at a high level — the price of not driving each session.
3. **Expect the human in the loop.** Software is complex (Cynefin): however thorough the plan,
   work will surface decisions, missing facts and follow-ons. These are a first-class, expected
   part of a workflow, not a failure to be recovered from.
